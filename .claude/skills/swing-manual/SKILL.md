# Swing Manual

Reglas:
- Crear interfaces manualmente.
- Usar JFrame, JPanel, JButton, JLabel, JTextField.
- Usar CardLayout cuando existan múltiples vistas.
- Colores simples.
- Diseño estilo universitario.
- Variables en español.
- Métodos en español.

Evitar:
- WindowBuilder
- GUI builders
- Dependencias externas

Ejemplo de estructura:
- VentanaPrincipal
- PanelMenu
- PanelConfiguracion
- PanelJuego
